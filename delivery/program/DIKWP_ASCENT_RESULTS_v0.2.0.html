04 / What the end-to-end test established
Canary drift requests review; it does not replace the model. HMAC and database transactions authenticate the local installation, not the truth of inputs or a human's identity. A compromised host is outside the reference threat model.


05 / Implementation scope
Regression candidates choose from x, x², x³, sin(x), cos(x) and a declared proxy. Scheduling candidates select a priority exponent and bounded swap passes. The trusted runtime fits or executes these typed programs. There is no arbitrary Python, shell, browser control, online training or self-granted privilege.
Public synthetic reproducibility is not an independent hidden evaluation. The next scientific milestone requires new data, an independent evaluator and stronger same-budget comparisons—not a different product name.
