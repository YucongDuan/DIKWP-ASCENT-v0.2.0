# Changelog

## 0.2.0 — 2026-09-08

- Frozen deployed-incumbent evaluation; no refit of accepted coefficients.
- Mandatory per-world fixed-strong-reference gate before local approval.
- Live loopback console over the real controller; JSON, Host, Origin and token checks.
- Frozen-model inference, labeled canary monitoring, parameter-only export.
- Predeclared campaigns with failed and unrun trials retained; finite global deadline.
- Explicit CSV split intake and file-only external candidate requests.
- Transaction-consistent audit reads for concurrent UI status polling.
- Full synthetic adoption/replay/drift/stop/rollback walkthrough.
- Added operation, API, malformed-input and strong-reference regression tests.
- Replaced outdated v0.1 public results with an explicitly offline evidence viewer.

Known gaps: no foundation weights, no live LLM connector, no OS sandbox, no independent
secret holdout, no production server, no bank/legal authority, no proven ASI.
