Trust boundary
Candidate programs are data in an allowlisted numerical grammar. This server accepts only loopback requests with a local session token and rejects cross-origin control requests. It provides no proxy, arbitrary path, shell, provider or payment endpoint.
Its OS user, source code, local controller key and database remain trusted. Module separation is not a production sandbox. Public synthetic data are not secret holdout data.
Unknown performance is allowed. Failed evidence is retained. ASI status is never inferred from these tasks.
